# Tracegram

Tracegram is a web app built with **Next.js, TailwindCSS, and shadcn/ui** that helps you track Instagram follower changes over time.  
You can paste or upload two follower snapshots (old vs new) and instantly see:

- ✅ Who unfollowed  
- ✅ Who is new  
- ✅ Who stayed the same  
- ✅ Duplicate entries in your data  

---

## 🚀 Tech stack
- [Next.js 15](https://nextjs.org/) – React framework for modern web apps
- [TypeScript](https://www.typescriptlang.org/) – safer, typed JavaScript
- [Tailwind CSS](https://tailwindcss.com/) – utility-first styling
- [shadcn/ui](https://ui.shadcn.com/) – accessible UI components built on Tailwind

---

## 🖥️ Development setup

### 1. Clone the repo
```bash
git clone https://github.com/YOUR-USERNAME/tracegram.git
cd tracegram
```

### 2. Install dependencies

```bash
npm install
```

### 3. Run the dev server

```bash
npm run dev
```

Then open http://localhost:3000 in your browser.
